# Contact Book

A simple Contact Book application built using Python.

## Features
- Add new contacts
- View all contacts
- Search contacts
- Delete contacts
- Easy-to-use menu interface

## Technologies Used
- Python

## How to Run
1. Download or clone the repository.
2. Open the project in Python.
3. Run the program.
4. Follow the on-screen menu options.

- Loops
